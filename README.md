# 羽球排場次

羽球排場工具，資料只存在使用者裝置的瀏覽器（`localStorage`），沒有後端、沒有帳號。

## 檔案結構

```
index.html   HTML 結構
style.css    樣式
app.js       排場邏輯與畫面互動
```

三個檔案用相對路徑引入，GitHub Pages 或雙擊 `index.html` 離線開啟都能正常運作，不需要伺服器或建置流程。下載/部署時三個檔案要放在同一個資料夾。

## 功能

- 「球員與場地設定」頁（球員名單排在最上方）：
  - 球員管理：姓名、程度 (1-12，另有「12以上」)、固定搭檔
    - 可一位一位新增，也可以在「批次新增」貼上多行文字一次新增
    - 匯出/匯入球員名單 CSV（空白分隔，只含姓名、程度、搭檔）
    - 每位球員用 3 個按鈕操作狀態：**未報到／已報到**切換是否到場；**休息**、**離場**是開關（亮＝啟用）。只有「已報到」且「休息」「離場」都關閉的人會被排入對戰
    - 「全部標記已報到」一鍵把整批未報到的人改成已報到
  - 場地設定：可調整場地數量、單打/雙打模式（這是「預設值」，排場時每一輪仍可個別覆蓋）。中途加開會立刻多一片空場地；中途減少時，若該場地正在進行未確認比分的對戰，會先標記「最後一輪」（紅框），等比分確認後才真正移除
- 右上角「➕ 開新場」按鈕：跳出視窗，可選填批次貼上名單／匯入 CSV，加上場地數量與模式，按「開場」後會清空上次的上場次數／比分／歷史紀錄並直接進入排場頁。名單沒設定或人數有增減，之後都可以到「球員與場地設定」頁調整
- 「排場」頁：每片場地各自獨立記錄輪數與對戰，「產生下一輪」「重排這一輪」按鈕都在各場地卡片內，未確認比分就按下這兩個按鈕會先跳出確認框。
  - 按下後可先調整「本輪模式」（預設帶入場地設定的單打/雙打，這一輪要改也可以），下面列出目前可上場的每一位球員，名字旁有「隨機／左隊／右隊」三個按鈕
  - 留在「隨機」的人由系統依已上場次數、等待輪數、程度平衡、避免重複對手/搭檔自動決定要不要上場、上哪一隊；指定「左隊」或「右隊」的人一定照指定上場，其餘空位按「確認產生」後自動補上——全部留隨機＝全自動、指定幾位＝半自動、整場都指定＝全手動，都是同一套操作
  - 固定搭檔只要都在場，指定其中一人也會自動把搭檔拉進同一隊
  - 比分用實際分數輸入（非單純左右邊勝負），送出後自動判定勝負並更新戰績，可重新輸入更正
  - 候補/未上場區列出每位球員的程度、已上場次數與目前原因（未報到／休息／離場／候補）
- 「記錄」頁：查看每人上場次數與勝率、每片場地每輪的比分歷史紀錄

## 球員名單 CSV 格式

每行一位球員，欄位用空白分開：

```
姓名 程度(1-12或12+) 搭檔姓名(選填，無則留空或填 -)
```

例如：

```
王小明 6 陳小華
陳小華 4 王小明
林美美 12+
```

匯出/匯入僅包含姓名、程度、搭檔，不含上場次數、勝負與歷史紀錄（那些屬於單次場次的即時資料，用「開新場」重新開始）。透過「開新場」視窗新增的球員預設「未報到」，之後在「球員與場地設定」頁把已到場的人改成「已報到」即可排入輪替；在主頁面直接新增／批次新增的球員則預設「已報到」。

## 使用方式（兩種都可以）

1. **線上使用**：直接開啟 GitHub Pages 網址（見下方設定步驟）。
2. **離線使用**：把 `index.html`、`style.css`、`app.js` 三個檔案下載到同一個資料夾，雙擊 `index.html` 用瀏覽器開啟即可，不需要網路。

## 部署到 GitHub Pages

1. 在 GitHub 建立一個新 repository（public 或 private 皆可，Pages 免費方案 public 較方便）。
2. 把這個資料夾的內容 push 上去：
   ```bash
   git remote add origin <你的 repo 網址>
   git branch -M main
   git push -u origin main
   ```
3. 到 repo 的 **Settings → Pages**，Source 選擇 `Deploy from a branch`，Branch 選 `main` / `(root)`，儲存。
4. 幾分鐘後即可用 `https://<你的帳號>.github.io/<repo名稱>/` 開啟。
5. 若有自己的網域，也可以在 Pages 設定加上 Custom domain。

## 資料備份提醒

所有資料都只存在瀏覽器的 `localStorage`，換裝置、清瀏覽器資料都會遺失。建議定期在「球員與場地設定」頁按「匯出名單 (CSV)」保存檔案。
