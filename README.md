# 排場小幫手

多球種排場工具（羽球／匹克球／網球），資料只存在使用者裝置的瀏覽器（`localStorage`），沒有後端、沒有帳號。

## 檔案結構

```
index.html   HTML 結構
style.css    樣式
app.js       排場邏輯與畫面互動
```

三個檔案用相對路徑引入，GitHub Pages 或雙擊 `index.html` 離線開啟都能正常運作，不需要伺服器或建置流程。下載/部署時三個檔案要放在同一個資料夾。

## 功能

- 右上角「➕ 開新場」左邊的圖示按鈕可切換深色／淺色主題：預設跟隨系統，點一下依序切換「跟隨系統／淺色／深色」，選擇會記在瀏覽器裡
- 「球員設定」頁：
  - 球員名單是一張表格（姓名／程度／搭檔／狀態／編輯），表格下方是新增單一球員的小工具列（姓名／程度／搭檔／圓形「＋」按鈕），不受表格欄寬限制
    - 也可以在「批次新增」貼上多行文字一次新增
    - 匯出/匯入球員名單 CSV（空白分隔，只含姓名、程度、搭檔）
    - 每位球員用 3 個按鈕操作狀態：**未報到／已報到**切換是否到場；**休息**、**離場**是開關（亮＝啟用）。只有「已報到」且「休息」「離場」都關閉的人會被排入對戰
    - 「全部標記已報到」一鍵把整批未報到的人改成已報到
    - 姓名不能空白、程度一定要是數字，超過/低於球種的範圍會自動修正到上限/下限
    - 姓名不能重複：新增單一球員、批次新增、CSV 匯入、開新場的批次貼上/匯入都會檢查，跟現有名單重複或同一批次內自己重複的名字會被擋下或略過（略過時會告訴你哪些名字被跳過）
    - 每一列「編輯」欄有鉛筆（修改）、垃圾桶（刪除）兩個圖示按鈕。點鉛筆可以編輯該列的**程度／搭檔**（姓名不可修改），搭檔可以改成其他人、也可以改回「無搭檔」清除搭檔，內容預設是修改前的資料，改完按「儲存」或「取消」
    - 已上場次數改到「記錄」頁查看（球員設定頁只顯示名單本身的資料，不重複顯示上場統計）
- 右上角「➕ 開新場」按鈕：跳出視窗，**第一項先選球種**（決定程度的數值範圍，見下方），可選填批次貼上名單／匯入 CSV，加上場地數量與模式，按「開場」後會清空上次的上場次數／比分／歷史紀錄並回到「球員設定」頁，方便先讓球員報到。名單沒設定或人數有增減，之後都可以到「球員設定」「排場」頁調整
- 「排場」頁：
  - 場地卡片只顯示目前比賽的球員與比分輸入，按下「確認比分」後場地立刻釋出（變空場地），可以再指派下一組人上場；比分列最右邊還有「中途下場」，用在比賽被迫中止、不會有比分的情況——按下後場地立刻釋出，但不記錄比分或勝負，該場次也不計入球員的已上場次數（已上場次數只在比分確認後才累加）
  - 場地號碼旁邊是鉛筆圖示按鈕：按下讓號碼欄位可以編輯，改完按綠色打勾圖示存檔，「下一輪預排」的場地選單會立刻更新成新名稱；右上角「➕ 新增場地」隨時加開；每片場地卡片右上角有垃圾桶圖示「移除」——按下後不會馬上刪除，而是先標記待移除、圖示換成「復原」讓你可以撤銷；空場地要再按一次「確定移除」才會真的刪除，比賽中的場地則是等比分確認後才真正移除
  - 「下一輪預排」是排場的核心：已經排好、還沒上場的輪次列在上面，「➕ 預排一輪」按鈕在下面。按下按鈕選比賽模式（單打/雙打），面板上方會即時顯示「左隊 vs 右隊」的預覽，候選名單每一列名字緊接著就是該球員的「隨機／左隊／右隊」三個按鈕（名字後面若有固定搭檔會標示「- 搭檔名稱」）——留「隨機」的人，系統優先叫已上場次數最少的人補上空位，次數相同的人之間才會再依程度平衡、避免重複對手/搭檔去挑選、也會稍微偏好等待較久的人；指定「左隊」或「右隊」的人一定照指定上場，其餘空位按「確認預排」後自動補上（全部留隨機＝全自動、指定幾位＝半自動、指定滿＝全手動）。固定搭檔指定其中一人會自動拉搭檔進同一隊
    - 可以一次預排好幾輪；每個已排好的輪次「指派上場」按鈕右邊有「修改」，可以用同一套左隊/右隊面板調整（面板會保留修改前的分隊），「移除」按鈕獨立放在最右邊避免手滑誤按
  - 「板凳區」列出已報到、還沒上場的球員（未報到的人不會顯示），依上場數由少到多排序（同上場數再依程度由低到高），依序標示狀態（休息／離場／已預排／候補）與上場數，名字後面若有固定搭檔會標示「- 搭檔名稱」
- 「記錄」頁：查看每人上場次數與勝率、每片場地每場的比分歷史紀錄；右上角「⬇ 匯出紀錄」把球員統計與歷史紀錄匯出成 CSV

## 球種與程度範圍

程度的數值範圍依球種而定，開新場時第一項選擇。範圍定義寫在 `app.js` 最上面的 `SPORT_CONFIGS`，要調整範圍或加新球種改那裡即可：

| 球種 | 範圍 | 級距 |
| --- | --- | --- |
| 羽球 | 3 ~ 12 | 1 |
| 匹克球 | 1.0 ~ 5.0 | 0.5 |
| 網球 | 1.0 ~ 7.0 | 0.5 |

新增/批次新增/開新場批次新增球員時都會檢查：姓名不能空白，程度一定要是數字，超過上限自動改成上限、低於下限自動改成下限。切換球種（例如從羽球換成匹克球）也會把既有球員的程度重新裁切到新範圍內。

## 球員名單 CSV 格式

每行一位球員，欄位用空白分開：

```
姓名 程度 搭檔姓名(選填，無則留空或填 -)
```

例如（羽球）：

```
王小明 6 陳小華
陳小華 4 王小明
林美美 3
```

匯出/匯入僅包含姓名、程度、搭檔，不含上場次數、勝負與歷史紀錄（那些屬於單次場次的即時資料，用「開新場」重新開始）。透過「開新場」視窗新增的球員預設「未報到」，之後在「球員設定」頁把已到場的人改成「已報到」即可排入輪替；在主頁面直接新增／批次新增的球員則預設「已報到」。

## 使用方式（兩種都可以）

1. **線上使用**：直接開啟 GitHub Pages 網址（見下方設定步驟）。
2. **離線使用**：把 `index.html`、`style.css`、`app.js` 三個檔案下載到同一個資料夾，雙擊 `index.html` 用瀏覽器開啟即可，不需要網路。

## 部署到 GitHub Pages

1. 在 GitHub 建立一個新 repository（public 或 private 皆可，Pages 免費方案 public 較方便）。
2. 把這個資料夾的內容 push 上去：
   ```bash
   git remote add origin <你的 repo 網址>
   git branch -M main
   git push -u origin main
   ```
3. 到 repo 的 **Settings → Pages**，Source 選擇 `Deploy from a branch`，Branch 選 `main` / `(root)`，儲存。
4. 幾分鐘後即可用 `https://<你的帳號>.github.io/<repo名稱>/` 開啟。
5. 若有自己的網域，也可以在 Pages 設定加上 Custom domain。

## 資料備份提醒

所有資料都只存在瀏覽器的 `localStorage`，換裝置、清瀏覽器資料都會遺失。建議定期在「球員設定」頁按「匯出名單 (CSV)」保存檔案。
