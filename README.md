# 羽球排場次

羽球排場工具，資料只存在使用者裝置的瀏覽器（`localStorage`），沒有後端、沒有帳號。

## 檔案結構

```
index.html   HTML 結構
style.css    樣式
app.js       排場邏輯與畫面互動
```

三個檔案用相對路徑引入，GitHub Pages 或雙擊 `index.html` 離線開啟都能正常運作，不需要伺服器或建置流程。下載/部署時三個檔案要放在同一個資料夾。

## 功能

- 「球員與場地設定」頁：
  - 球員名單是一張表格，最後一列固定是「新增球員」欄位（姓名／程度／搭檔／新增按鈕），不用另外找地方新增
    - 也可以在「批次新增」貼上多行文字一次新增
    - 匯出/匯入球員名單 CSV（空白分隔，只含姓名、程度、搭檔）
    - 每位球員用 3 個按鈕操作狀態：**未報到／已報到**切換是否到場；**休息**、**離場**是開關（亮＝啟用）。只有「已報到」且「休息」「離場」都關閉的人會被排入對戰
    - 「全部標記已報到」一鍵把整批未報到的人改成已報到
    - 姓名不能空白、程度一定要是數字，超過/低於球種的範圍會自動修正到上限/下限
- 右上角「➕ 開新場」按鈕：跳出視窗，**第一項先選球種**（決定程度的數值範圍，見下方），可選填批次貼上名單／匯入 CSV，加上場地數量與模式，按「開場」後會清空上次的上場次數／比分／歷史紀錄並直接進入排場頁。名單沒設定或人數有增減，之後都可以到「球員與場地設定」「排場」頁調整
- 「排場」頁：
  - 場地卡片只顯示目前比賽的球員與比分輸入，按下「確認比分」後場地立刻釋出（變空場地），可以再指派下一組人上場
  - 場地號碼可以直接點開修改；右上角「➕ 新增場地」隨時加開；每片場地卡片右上角有紅色「移除」——場地空的話直接移除，還在比賽中的話會先標記「最後一場」，等比分確認後才真正移除
  - 「下一輪預排」是排場的核心：按「➕ 預排一輪」選比賽模式（單打/雙打），每位可上場的球員名字旁有「隨機／左隊／右隊」三個按鈕——留「隨機」由系統依已上場次數、程度平衡、避免重複對手/搭檔自動決定要不要上場、上哪隊；指定「左隊」或「右隊」的人一定照指定上場，其餘空位按「確認預排」後自動補上（全部留隨機＝全自動、指定幾位＝半自動、指定滿＝全手動）。固定搭檔指定其中一人會自動拉搭檔進同一隊
    - 可以一次預排好幾輪，排好的輪次會列在下面，等場地空出來後選要指派去哪一片場地
  - 候補/未上場區列出每位球員的程度、已上場次數與目前原因（未報到／休息／離場／已預排／候補）
- 「記錄」頁：查看每人上場次數與勝率、每片場地每場的比分歷史紀錄；右上角「⬇ 匯出紀錄」把球員統計與歷史紀錄匯出成 CSV

## 球種與程度範圍

程度的數值範圍依球種而定，開新場時第一項選擇。範圍定義寫在 `app.js` 最上面的 `SPORT_CONFIGS`，要調整範圍或加新球種改那裡即可：

| 球種 | 範圍 | 級距 |
| --- | --- | --- |
| 羽球 | 3 ~ 12 | 1 |
| 匹克球 | 1.0 ~ 5.0 | 0.5 |
| 網球 | 1.0 ~ 7.0 | 0.5 |

新增/批次新增/開新場批次新增球員時都會檢查：姓名不能空白，程度一定要是數字，超過上限自動改成上限、低於下限自動改成下限。切換球種（例如從羽球換成匹克球）也會把既有球員的程度重新裁切到新範圍內。

## 球員名單 CSV 格式

每行一位球員，欄位用空白分開：

```
姓名 程度 搭檔姓名(選填，無則留空或填 -)
```

例如（羽球）：

```
王小明 6 陳小華
陳小華 4 王小明
林美美 3
```

匯出/匯入僅包含姓名、程度、搭檔，不含上場次數、勝負與歷史紀錄（那些屬於單次場次的即時資料，用「開新場」重新開始）。透過「開新場」視窗新增的球員預設「未報到」，之後在「球員與場地設定」頁把已到場的人改成「已報到」即可排入輪替；在主頁面直接新增／批次新增的球員則預設「已報到」。

## 使用方式（兩種都可以）

1. **線上使用**：直接開啟 GitHub Pages 網址（見下方設定步驟）。
2. **離線使用**：把 `index.html`、`style.css`、`app.js` 三個檔案下載到同一個資料夾，雙擊 `index.html` 用瀏覽器開啟即可，不需要網路。

## 部署到 GitHub Pages

1. 在 GitHub 建立一個新 repository（public 或 private 皆可，Pages 免費方案 public 較方便）。
2. 把這個資料夾的內容 push 上去：
   ```bash
   git remote add origin <你的 repo 網址>
   git branch -M main
   git push -u origin main
   ```
3. 到 repo 的 **Settings → Pages**，Source 選擇 `Deploy from a branch`，Branch 選 `main` / `(root)`，儲存。
4. 幾分鐘後即可用 `https://<你的帳號>.github.io/<repo名稱>/` 開啟。
5. 若有自己的網域，也可以在 Pages 設定加上 Custom domain。

## 資料備份提醒

所有資料都只存在瀏覽器的 `localStorage`，換裝置、清瀏覽器資料都會遺失。建議定期在「球員與場地設定」頁按「匯出名單 (CSV)」保存檔案。
